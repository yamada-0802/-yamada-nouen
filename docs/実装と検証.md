# 実装・検証結果

## 作業版の状態

GitHub Pages向け静的HTML/CSS/JavaScript構成。実写真、問い合わせ先、SNSはユーザー指定で未設定。お知らせも実データ未提供につき未設定です。代替写真・架空投稿・ダミーアカウントを表示していません。外部フレームワークや秘密のアクセストークンは使用していません。

## 正本との比較・修正

PC/スマホの実ブラウザスクリーンショットを取得し、正本と比較しました。
- トップは農園名・所在地・英字・キャッチコピーを中央に配置。
- PCの農園紹介は左文章・右写真枠、商品紹介は左写真枠・右白背景。
- 農園紹介の上揃え、スマホ見出しの青い斜線、ギャラリーの移動・現在位置表示を修正。
- ギャラリーの名前は機能仕様を優先して「作業・生育状況」に統一。
- 375px/390pxは、指示書の小さな文字・極端な2カラムを避ける要件に合わせて縦並び。正本の2カラムを縮小した見た目とは異なります。
- 最下部のInstagramとXは隣同士を維持。
- 未確認の家族経営等の文言は追加せず、既存の紹介文・水稲情報を維持。
- 写真とブランドロゴの個別素材は未提供。写真の見え方、夕景の構図、ブランドロゴは再現未完了です。写真を設定した後に再比較が必要です。
- 未設定状態の説明・管理手順リンクの分だけ、参考画像から段の高さに差があります。厳密な視覚的一致が完了したとは扱っていません。

## 動作確認

Chromiumで1440・768・390・375pxを確認。全幅でページ全体の横はみ出しなし、JavaScript実行エラーなし。写真ギャラリー内だけ横スクロール可能。

メニューのクリック開閉、Esc、項目選択、画面外クリックでの終了を確認。キーボードでの開閉・リンクへの移動も確認対象。

写真データをQAの通信内だけ差し替えて、追加・並び替え・写真差し替え・削除がリロード後に反映されることを確認。本番JSONは空配列を維持しています。画像は自然な縦横比で表示します。

## 反映状況

GitHub連携の認可後、作業用ブランチ codex/reference-design-20261103 に実装を保存。mainと公開サイトには未反映です。

## 変更ファイル

- index.html：各セクション、メニュー、写真の未設定表示、情報とSNSの配置
- css/style.css：PC・タブレット・スマホの見た目、写真スクロール
- js/app.js：メニュー、写真・リンク設定、ギャラリー、お知らせ表示
- js/content.js：JSON読み込み、写真データ検証と並び替え、安全なリンク判定
- data/gallery.json / news.json / settings.json：更新可能なデータと設定

- docs/写真と設定の更新.md：iPhoneによる写真更新手順
- README.md：起動・設定・公開手順
