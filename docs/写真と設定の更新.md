## 写真の追加

1. SafariでGitHubにログインし、`yamada-0802/-yamada-nouen` を開きます。
2. `assets/gallery/` を開き、Add file → Upload filesで自分の写真をアップロードします。表示されない場合はSafariの「デスクトップ用Webサイトを表示」を使用します。
3. ファイル名は `planting-01.jpg` のような英数字を使用し、Commit changesで保存します。
4. `data/gallery.json` を開き、鉛筆の編集ボタンから配列に項目を追加します。

以下は入力形式の説明用です。実際の写真に合わせて書き換えてください。日付不明ならnullを維持してください。

```json
[
  {
    "path": "assets/gallery/planting-01.jpg",
    "caption": "定植",
    "order": 1,
    "date": null,
    "alt": "写真の内容を具体的に説明する文章",
    "width": 1600,
    "height": 1200
  }
]
```

widthとheightは実画像のピクセル寸法です。不明なら両方の項目を省略できます。末尾の項目に余分なカンマを付けないでください。

5. Commit changesで保存します。既存のPages公開処理が成功した後、サイトを再読み込みして確認します。

## 差し替え・削除・並び替え

- 差し替え：新しい名前で画像をアップロードし、対象項目のpath・alt・寸法を変更します。別名にすることで古い画像のキャッシュを避けます。
- 削除：先にJSONから該当する項目を削除して保存します。その後、不要になった画像をGitHubの削除操作で削除します。ほかの箇所で使う画像は削除しないでください。
- 並び替え：orderを1、2、3…と変更して保存します。小さい順に表示します。

## お知らせ・リンク

`data/news.json` は未提供につき空配列です。実際の掲載日をdate（YYYY-MM-DD形式）、本文をtextに設定したオブジェクトを配列に追加すると画面に反映されます。

`data/settings.json` のcontactUrl、instagramUrl、xUrlに実際の送信先・アカウントを設定します。未設定はnullのままにし、他人のアカウントやダミーURLを入れないでください。GitHub Pages自体にメール送信機能はないため、contactUrlには利用中の外部フォームのhttps URL、またはmailto:で始まるメール宛先を設定します。

GitHubのアクセストークンやパスワードは、JSON・HTML・JavaScriptに書かないでください。
